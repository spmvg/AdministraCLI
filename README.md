# AdministraCLI

Command line tool for small business administration with local data in an Excel sheet.

## Installation

```bash
pip install administracli
```

## Usage

```bash
python -m administracli --help
```

### Commands

| Command | Description |
|---------|-------------|
| `init [FILE]` | Create a new Excel sheet with the proper format. Default: `administracli.xlsx`. |
| `run [FILE]` | Interactively close the books, then show financial reports. |

### Workflow

1. Run `init` to create an empty Excel sheet.
2. Enter your transactions and invoices in Excel.
3. Run `run`. The TUI guides you through what is left to do (matching, categorising, etc.). Once the books are closed, the balance sheet and profit-and-loss statement are shown.
4. If nothing is left to do, the reports are shown immediately.

## Principles

* Data is stored locally in an Excel sheet.
* Columns starting with an underscore (`_...`) are autogenerated by AdministraCLI. Users should not edit them.
* AdministraCLI interactively guides users through a TUI to close the books (match transactions to invoices, assign categories, etc.).
* Once the books are closed, AdministraCLI shows a balance sheet and profit-and-loss statement.

## Rules

### Closing checks

The books are closed when every check passes:
* Every transaction has a `_category`.
* Every transaction with category `incoming_invoice` has a `_invoice_id` matched to an `incoming_invoices` `_id`.
* Every transaction with category `outgoing_invoice` has a `_invoice_id` matched to an `outgoing_invoices` `_id`.
* Every invoice in `incoming_invoices` is referenced by at least one transaction.
* Every invoice in `outgoing_invoices` is referenced by at least one transaction.

Note: `incoming_invoices` are invoices received from suppliers (costs). `outgoing_invoices` are invoices sent to customers (revenue).

### Reports

When the books are closed, the following are printed:
* **Balance sheet**: totals per category where the category type is `asset` or `liability`.
* **Profit-and-loss statement**: totals per category where the category type is `income` or `expense`.

Totals are computed by summing the `Amount` of all transactions in each category.

## Excel format

Each worksheet is a table with column names in the first row and data in subsequent rows.

### Worksheets

| Worksheet | Description |
|-----------|-------------|
| `transactions` | Bank transactions. |
| `incoming_invoices` | Invoices received from suppliers (costs). |
| `outgoing_invoices` | Invoices sent to customers (revenue). |

### Columns

#### `transactions`

| Column | Description |
|--------|-------------|
| `Date` | Transaction date. |
| `Amount` | Transaction amount. |
| `Description` | Description from the bank. |
| `_id` | Autogenerated unique identifier. |
| `_invoice_id` | Autogenerated: matched invoice `_id`. Only set for `incoming_invoice` and `outgoing_invoice` categories. |
| `_category` | Autogenerated: assigned category (e.g. `capital`, `generic_costs`, `incoming_invoice`). |

#### `incoming_invoices`

| Column | Description |
|--------|-------------|
| `Date` | Invoice date. |
| `Amount` | Invoice amount. |
| `Counterparty` | Supplier name. |
| `_id` | Autogenerated unique identifier. |

#### `outgoing_invoices`

| Column | Description |
|--------|-------------|
| `Date` | Invoice date. |
| `Amount` | Invoice amount. |
| `Counterparty` | Customer name. |
| `_id` | Autogenerated unique identifier. |

### Categories

Categories are assigned to transactions during the interactive TUI. Built-in categories:

| Category | Type | Description |
|----------|------|-------------|
| `capital` | `asset` | Owner equity and capital contributions. |
| `generic_costs` | `expense` | General business expenses. |
| `incoming_invoice` | `expense` | Costs from invoices received. |
| `outgoing_invoice` | `income` | Revenue from invoices sent. |
